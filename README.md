# Yet another agent

How difficult can it be to build an LLM-powered app in the go ecosystem? Well, let's see.

This is going to be a personal agent that lives in Telegram, so that I can forward posts to him, ask him to set remminders, add links to reading list and so on.

The project is for recreational purposes. Hence,

- going slow is allowed;
- mistakes are allowed;
- abandoning the project is allowed but not encouraged;
- hand-written code is preferred;
- agentic coding is allowed, but not encouraged (enough of that at the day job);
- agentic help in the form of explanations and training is welcomed.
